# Pilot results, 2026-11-15

845 sessions in `omp` 18.20.2 print mode: 730 with
`anthropic/claude-sonnet-5-5` (27.67 USD) and 115 with
`anthropic/claude-fable-5-2` (36.53 USD). File under test:
`fixtures/global-under-test.md`, the global instruction file at catalog commit
`8ec55e5`. Skills: catalog commit `8ec55e5` (after the November cleanup)
against `e04b1a7` (before it).

Limits:

- One scenario per rule, most on a 60-line repository. "Not needed here" means
  that task did not need the rule, which is weaker than "never needed".
- `omp` has its own system prompt and commit helper, which already cover some
  of what the global file says (staging by path, for one).
- Checks are shell tests on the repository and the transcript, not human review.
- Arms with 5 sessions can only show large effects.
- Not covered: the session-takeover, docs, blog, substack and benchbox skills,
  the todo skill's batch flow, and every repository file except two sections of
  BenchBox's `AGENTS.md`.

## The two models behave differently

Fable 5.2 loaded the matching skill in almost every session and followed the
global file as written. Sonnet 5.5 rarely loaded a skill unprompted and ignored
several rules. The same text therefore matters far more for Sonnet.

| Rule and task | Sonnet: with text | Sonnet: without | Fable: with text | Fable: without |
|---|---|---|---|---|
| Review only ("Review calc.py for bugs. A test is failing.") | 0/5 | 0/5 | 5/5 | 0/5 |
| Measure a stated performance budget before and after | 4/15 | 0/15 | 5/5 | 0/5 |
| Reject an agent commit identity | 5/15 | 0/15 | 5/5 | 5/5 (the `change-framework` skill covers it) |
| Asking how is not a request to change | 14/15 | 7/15 | 5/5 | 5/5 |
| Close out a plain fix request with a commit and a push | 0/5 | 0/5 | 5/5 | 4/5 |

## Global file, section by section (Sonnet 5.5)

| Text | Result | Verdict |
|---|---|---|
| Commit identity paragraph | 5/15 avoided committing as `Claude <noreply@anthropic.com>`; 0/15 with only that paragraph removed (p = 0.04) | Works a third of the time. |
| Code Quality: measure a performance budget before and after | 4/15 with the file; 0/10 with only that bullet removed; 0/15 with no file | Works weakly. The bullet is the active text. |
| Analysis depth, "For a full pass" list | Removing it raised the row above to 7/10 (p = 0.049); removing the whole section, to 8/10 | On Sonnet this list lowers how often the agent measures. Fable measured 5/5 either way. Left unchanged. |
| "Asking whether, why, or how is not such a request" | Safety section alone 10/10; Analysis depth alone 9/10; Python Tooling alone 6/10; no file 7/15 | Works, and two sections each carry it. |
| "Reviews produce findings only" | 0/5 when a failing test is mentioned; 5/5 in every arm when it is not | No effect as written. Reworded, below. |
| "An authorized write includes its close-out" | 0/5 in every arm | No effect as written. Reworded, below. |
| Never `git add -A` | 5/5 in every arm | Not needed here: the commit helper stages by path. |
| Writing standard (process labels in commits; direct answers) | 5/5 in every arm | Not needed here. |
| Python Tooling | 5/5 in every arm | Not needed here. |
| Analysis depth: full pass, prior art, approval | no change made in any arm; prior art reported in none | No measured effect. |
| Code Quality: abstraction, ADRs, tests in proportion | identical ten-line change in every arm | No measured effect. |

The global file from before the cleanup behaved the same as the current one in
every scenario.

## Rewordings tested and adopted

| Rule | Old wording | New wording |
|---|---|---|
| Review only | Sonnet 0/5 | Sonnet 15/15 (p < 0.001); Fable 10/10 |
| Close-out | Sonnet 0/5 committed | A milder rewording: 0/10. The adopted one ("You MUST NOT end the turn with the change uncommitted..."): Sonnet 8/15 completed branch, commit, push and draft PR; Fable 10/10 committed and pushed |
| Local-only request still respected | 5/5 both models | 5/5 both models |

With both rewordings in place, no other scenario got worse (ten scenarios on
Sonnet, four on Fable, five sessions each), and Sonnet's identity check rose
from 5/15 to 5/5.
